## 🇪🇸 Español

### 🚀 Sobre esta versión (v1.5 - ACTUAL)
**Esta es la versión final, pulida y completa**. Un diseño completamente Premium con animaciones inmersivas, organización estricta en base a un directorio `api` abstraído, e integración total preparatoria para Ads.

### 📝 Novedades de la versión (Changelog vs v1.4)
* **API Dedicada con Seguridad Limpia:** Descentralización masiva de contraseñas. El entorno interno `/api` resguarda ahora de forma inmaculada `api.php` delegando variables en `db_config.php`.
* **Soporte Abstracto Moderno:** Las partes compartidas (`header` o futuros elementos) se mudaron exitosamente a una estricta carpeta corporativa nativa: `/components`.
* **Despliegue Monetario Listo:** Alta compatibilidad SEO e inclusión nativa del componente validatorio `ads.txt`.
* Aplicación de un entorno de protección adicional bloqueando envíos de GIT accidentales a través de un archivo `.gitignore`.
