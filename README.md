## 🇪🇸 Español

### 🚀 Sobre esta versión (v1.0)
Esta es la **versión inicial (monolítica)** del proyecto Password Generation & Analyzer. Un sistema web donde tanto la estructura (HTML), los estilos y el código base (JavaScript) fueron originados aquí en una sola visualización fundamental para generar contraseñas seguras y probar su integridad.

### 📝 Novedades en esta versión
* Lanzamiento base del generador de contraseñas de alta seguridad.
* Estructura de "Single Page Application" clásica con archivos base (sin carpetas de organización).
* Inclusión de página de guía (`guia.html`) y core generador en HTML/JS base.

## 🇬🇧 English

### 🚀 About this version (v1.0)
This is the **initial (monolithic) release** of the Password Generation & Analyzer project. A web application where the structure, styles, and Javascript base logic were originally born as a single fundamental block to test and generate high-security passwords.

### 📝 Features in this release
* Core high-security password generation engine release.
* Classical simplistic file structure mapping without organization folders.
* Inclusion of a basic layout guide (`guia.html`) and raw core generation logic.
